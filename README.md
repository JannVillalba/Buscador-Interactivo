
# Buscador-Interactivo

Proyecto React + Vite para buscar usuarios en una base de datos local usando una API simulada con JSON Server.

## ¿Cómo usar?

1. Instala las dependencias:
	```bash
	npm install
	```
2. Inicia el servidor de la API local:
	```bash
	npm run server-api
	```
3. Inicia la aplicación React:
	```bash
	npm run dev
	```

La app estará disponible en `http://localhost:5173` y la API en `http://localhost:8000/usuarios`.
